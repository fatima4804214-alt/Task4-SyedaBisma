# E-Commerce Sales Data Visualization Project

## 📌 Project Overview
This project performs an End-to-End Exploratory Data Analysis (EDA) on an e-commerce sales dataset. It automates data cleaning, calculates key business KPIs, and generates corporate-ready visualizations to help business decision-making.

## 🛠️ Tools Used
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 📂 Deliverables Generated
* `Cleaned_Ecommerce_Data.csv` (Processed Dataset)
* `Revenue_by_Product.png`
* `Order_Status_Distribution.png`
* `Payment_Method_Analysis.png`
* `Monthly_Revenue_Trend.png`
* `Referral_Source_Revenue.png`
* `Quantity_vs_TotalPrice.png`
* `Top_10_Customers.png`
* `Correlation_Heatmap.png`

## 🚀 Key Highlights
* **Data Integrity:** Handled missing values and removed duplicate entries automatically.
* **Feature Engineering:** Extracted Months and Years from raw dates for trend analysis.
